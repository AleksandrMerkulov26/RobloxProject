# RobloxProject

Основная игра проекта находится в каталоге [NightRaid](NightRaid/). Корневой Rojo-проект — вспомогательная стартовая заготовка; для разработки игры используйте конфигурации внутри `NightRaid`.

## О игре

**NightRaid** — многопользовательский стелс-налёт на ночной склад. Вы проникаете в ангар, собираете ценности, прячетесь от охранника и успеваете выбраться через зону эвакуации. Добыча, которую вынесли живой, превращается в деньги для улучшения персонального убежища.

**Цикл раунда:**

1. **Убежище (12 с)** — общайтесь, выбирайте комплект у Оружейной, прокачивайте снаряжение у Скупщика.
2. **Сбор лута (95 с)** — тихо собирайте ценности, обходите лазеры, вскрывайте хранилище.
3. **Эвакуация (45 с)** — доберитесь до зелёной зоны и удержитесь в ней 5 секунд.

**Ключевые механики:**

- Крюк-кошка, фонарь, дымовые шашки и подбираемый тайзер.
- Хрупкая добыча бьётся при жёстком падении, а тяжёлая замедляет героя.
- Охранник реагирует на шум, лазеры, взлом сейфа и видит игрока по углу обзора; дым блокирует зрение.
- Три комплекта снаряжения и три апгрейда (рюкзак, дым, фонарь).
- **Ночные события** — каждый рейд случайный: Чёрная ночь, Красная тревога, Джекпот или Тихая ночь.
- **Серия рейдов** — каждый успешный рейд подряд даёт +10% к выручке (максимум +50%); провал обнуляет серию.
- В таблице игроков показываются деньги, число успешных рейдов и текущая серия.

**Управление (клавиатура и мышь):**

| Клавиша | Действие |
| --- | --- |
| WASD / пробел | Движение / прыжок |
| Q | Крюк-кошка |
| F | Фонарь |
| G | Дымовая шашка |
| E | Взять предмет, взломать, использовать станцию |
| B | Рюкзак |
| ЛКМ | Выстрел из тайзера (если подобран) |

> Сейчас в игре нет мобильного и геймпадного управления — см. [ROADMAP.md](ROADMAP.md).

## Требования

- [Roblox Studio](https://www.roblox.com/create)
- [Aftman](https://github.com/LPGhatguy/aftman) — менеджер инструментов проекта
- Rojo 7.7.1 и Selene 0.32.0 (устанавливаются через Aftman по файлу `NightRaid/aftman.toml`)

## Установка инструментов

Откройте терминал в каталоге `NightRaid`:

```bash
cd NightRaid
aftman install
```

## Запуск игры

Из каталога `NightRaid` выполните:

```bash
rojo serve default.project.json
```

Подключитесь к серверу через Rojo Plugin в Roblox Studio.

## Запуск автотестов

Тесты запускаются отдельно от обычной игры:

```bash
rojo serve test.project.json
```

После подключения Rojo Plugin запустите игру кнопкой Play и смотрите результат в окне Output. Сейчас набор содержит 81 проверку (логика лута, охраны, экономики, дыма, серии рейдов и ночных событий).

## Статический анализ Luau

Selene проверяет исходный код на распространённые ошибки и проблемные конструкции без запуска игры:

```bash
selene src
```

Настройки Roblox/Luau находятся в `NightRaid/selene.toml`.

## Сборка файлов place

```bash
rojo build default.project.json --output NightRaid.rbxlx
rojo build test.project.json --output NightRaidTests.rbxlx
```

GitHub Actions автоматически запускает Selene и проверяет, что обе конфигурации Rojo собираются при изменениях в `NightRaid/**` и при Pull Request в `main`. Проверка Selene анализирует исходники, но не заменяет запуск игровых тестов в Roblox Studio.

## Структура проекта

```text
NightRaid/src/
  shared/   Config, LootLogic, NightEvents — чистая логика, покрытая тестами
  server/   init.server.luau (раунды, охрана, данные), HideoutBuilder, MapBuilder
  client/   init.client.luau (интерфейс, крюк, фонарь, дым)
  tests/    TestRunner.server.luau
```
