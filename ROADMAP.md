# Дорожная карта NightRaid

Приоритеты расставлены по влиянию на то, чтобы игра зацепила подростковую аудиторию Roblox.

## P0 — без этого игру не увидит большая часть аудитории

- [ ] **Мобильное управление.** Сейчас всё на клавишах Q/F/G/B и ЛКМ. Нужны сенсорные кнопки (крюк, фонарь, дым, рюкзак, выстрел) и поддержка геймпада.
- [ ] **Обучение за 60–90 секунд.** Короткий первый рейд с подсказками и гарантированной первой наградой.
- [ ] **Иконка, описание и скриншоты** страницы игры в Roblox; ссылка на игру в README.

## P1 — удержание игроков

- [ ] Ежедневная награда и серия входов.
- [ ] Ежедневные контракты («вынеси 3 хрупких предмета», «пройди рейд, не включив тревогу»).
- [ ] Косметика: скины комплектов, следы крюка, эффекты дыма. Покупка за игровые деньги и за Robux.
- [ ] Лидерборд недели и рекордов (самая дорогая добыча, самая длинная серия).
- [ ] Больше ночных событий (Шторм, Двойной охранник, Обесточенные лазеры).

## P2 — социальная часть

- [ ] Кооперативные роли (разведчик, взломщик, носильщик) и совместные бонусы.
- [ ] Число охранников зависит от числа игроков на сервере.
- [ ] Приватные серверы и приглашение друзей с бонусом.
- [ ] Режим «Фото» и эмоции в убежище.

## Технический долг

- [ ] Разделить `server/init.server.luau` (около 1400 строк) на модули: раунды, охрана, данные игрока, сеть.
- [ ] Удалить или подключить `server/MapBuilder.luau` — сейчас это неиспользуемая копия `BuildFacility` из `init.server.luau`.
- [ ] Убрать дублирующий корневой Rojo-проект (`src/`, `default.project.json`) или перенести игру в корень.
- [ ] DataStore: добавить блокировку сессии (`UpdateAsync` без неё может перезаписать данные при входе на второй сервер) и повторные попытки при ошибках.
- [ ] Охранник строит новый путь через `PathfindingService` на каждом тике — кэшировать путь и пересчитывать реже.
- [ ] Запускать автотесты в CI (например через Lune), а не только вручную в Studio.
- [ ] Шум крюка отправляет клиент (`MakeNoise`); подумать о серверной проверке.
- [ ] Уровень убежища (`Hideout.Level`) сохраняется, но нигде не растёт.
